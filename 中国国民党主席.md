# 概述

[**中国国民党主席**](https://zh.wikipedia.org/wiki/中国国民党主席)，简称**国民党主席**，为[中国国民党](中国国民党.md)的最高领导人，同时也是[全国代表大会](https://zh.wikipedia.org/wiki/中國國民黨全國代表大會)、[中央委员会](https://zh.wikipedia.org/wiki/中國國民黨中央委員會)、[中央委员会常务委员会](https://zh.wikipedia.org/wiki/中國國民黨中央委員會常務委員會)之主席。

中国国民党的最高领导人一职之名称在历史上有数次改变，将**总会长**职位永久保留予其前身[兴中会](兴中会.md)首任总会长[杨衢云](https://zh.wikipedia.org/wiki/杨衢云)，**总理**职位永久保留予首任总理[孙中山](孙中山.md)，而**总裁**职位永久保留予首任总裁[蒋介石](蒋介石.md)。首任党主席为[蒋经国](https://zh.wikipedia.org/wiki/蒋经国)。
