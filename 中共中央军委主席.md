# 概述

[**中国共产党中央军事委员会主席**](https://zh.wikipedia.org/wiki/中国共产党中央军事委员会主席)，简称**中共中央军委主席**，1954年设立，是[中国共产党](https://zh.wikipedia.org/wiki/中国共产党)[中央军事委员会](https://zh.wikipedia.org/wiki/中央军事委员会)的负责人，为党的[主要领导人](https://zh.wikipedia.org/wiki/党和国家领导人)之一，属[正国级](https://zh.wikipedia.org/wiki/国家级正职)职务。与[国家中央军委主席](国家中央军委主席.md)合称“[**中央军委主席**](中央军委主席.md)”。
