# 概述

[**中华人民共和国武装力量**](https://zh.wikipedia.org/wiki/中华人民共和国军事)由[中国人民解放军](中国人民解放军.md)、[中国人民武装警察部队](https://zh.wikipedia.org/wiki/中国人民武装警察部队)和[中国民兵](https://zh.wikipedia.org/wiki/中国民兵)组成。

# 垂直路线

| **#** | **线**       | **路径**                                     | **顶端建制**           | **顶端主官**             |
| :---- | :----------- | :------------------------------------------- | :--------------------- | :----------------------- |
| 1     | **作战指挥** | 军委 → 战区 → 部队                           | 战区正战区             | 上将                     |
| 2     | **建设管理** | 军委 → 军种 → 部队                           | 军种正战区             | 上将                     |
| 3     | **国防动员** | 军委 → 国防动员部 → 省军区 → 军分区 → 人武部 | 国防动员部大军区级     | 中将（部长正战区职）     |
| 4     | **联勤保障** | 军委 → 联勤保障部队（武汉）→ 5 中心          | 副战区（列军兵种序列） | 中将                     |
| 5     | **武警**     | 党中央/军委 → 武警部队 → 内卫/机动/海警      | 武警部队正战区         | 上将（通常由军委委员兼） |
| —     | 监督三线     | 军委纪委 / 军委审计 / 军委政法委             | 各自主官               | —                        |
