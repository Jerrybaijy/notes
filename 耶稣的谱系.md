# 概述

[**耶稣的谱系**](https://zh.wikipedia.org/wiki/耶稣的谱系)，是[耶稣](耶稣.md)经由其俗世的父母（[玛利亚](<https://zh.wikipedia.org/wiki/马利亚_(耶稣的母亲)>)和[约瑟](https://zh.wikipedia.org/wiki/圣若瑟)）一支或两支的谱系，在《[圣经](圣经.md)》中记载于《[新约圣经](https://zh.wikipedia.org/wiki/新约圣经)·[对观福音书](https://zh.wikipedia.org/wiki/對觀福音書)》的2个段落：《[马太福音](https://zh.wikipedia.org/wiki/马太福音)》[太 1:1-17](<https://zh.wikisource.org/wiki/圣经_(和合本)/马太福音#第一章>)和《[路加福音](https://zh.wikipedia.org/wiki/路加福音)》[路 3:23-38](<https://zh.wikisource.org/wiki/圣经_(和合本)/路加福音#第三章>)。这2份耶稣的谱系都向上追溯到[大卫](https://zh.wikipedia.org/wiki/大卫王)乃至[亚伯拉罕](亚伯拉罕.md)；而《路加福音》中的谱系还继续向上，一直追溯到[亚当](https://zh.wikipedia.org/wiki/亚当)。这2份耶稣的谱系在亚伯拉罕和大卫之间的部分是一致的，但是在大卫以后的部分则有极大的差异。关于这个差异，有两个主流说法。

- 其一为[太 1:1-17](<https://zh.wikisource.org/wiki/圣经_(和合本)/马太福音#第一章>) 所述为[约瑟](https://zh.wikipedia.org/wiki/圣若瑟)的谱系，[路 3:23-38](<https://zh.wikisource.org/wiki/圣经_(和合本)/路加福音#第三章>) 所述为[玛利亚](<https://zh.wikipedia.org/wiki/馬利亚_(耶穌的母親)>)的谱系。
- 另一说法为[太 1:1-17](<https://zh.wikisource.org/wiki/圣经_(和合本)/马太福音#第一章>) 所述为[约瑟](https://zh.wikipedia.org/wiki/圣若瑟)的生父雅各的谱系，[路 3:23-38](<https://zh.wikisource.org/wiki/圣经_(和合本)/路加福音#第三章>) 所述为[约瑟](https://zh.wikipedia.org/wiki/圣若瑟)的继承父希里的谱系，因出于所罗门谱系的马但，生了雅各。马但死后，属拿单谱系的玛塔，娶了马但的寡妇，并生了希里。因此，希里和雅各是同母的兄弟。希里无子而死，雅各为他兄弟立后生了约瑟。约瑟根据血源是属雅各，但照着法律，又是属于希里。因此约瑟是他们二者的儿子。

犹太资料《耶路撒冷塔木德》承认[路 3:23-38](<https://zh.wikisource.org/wiki/圣经_(和合本)/路加福音#第三章>) 是玛利亚的家谱，称她为希里的女儿（哈吉雅书 2:4）。

- 可能是[约瑟](https://zh.wikipedia.org/wiki/圣若瑟)的谱系（但有遗漏）。所罗巴伯以后无法考证血缘关系。

- 所罗巴伯
    - 可能是毗大雅的儿子，撒拉铁的侄子。

    - 但一定是约雅斤的孙子。
- [太 1:8](<https://zh.wikisource.org/wiki/圣经_(和合本)/马太福音#第一章>) 乌西雅之前缺少4代王3代人：
  - 亚哈谢：约兰之子
  - 亚她利雅：亚哈谢之母
  - 约阿施：亚哈谢之子
  - 亚玛谢：约阿施之子
- [太 1:8](<https://zh.wikisource.org/wiki/圣经_(和合本)/马太福音#第一章>) 约雅斤之前缺少2代王1代人：
  - 约哈斯：约西亚之子
  - 约雅敬：约西亚之子
- 从[约雅斤](https://zh.wikipedia.org/wiki/约雅斤)（前615年或前605年—前562年）到约瑟（约前30年），约600年时间，共记载 13代人，每代人约45年，不符合常理（25年），所以个人认为，《马太福音 1:1-17》在约雅斤以后，也存在遗漏的情况。
