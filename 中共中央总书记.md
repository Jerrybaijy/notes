# 概述

[**中国共产党中央委员会总书记**](https://zh.wikipedia.org/wiki/中国共产党中央委员会总书记)，简称**中共中央总书记**或**总书记**，是当前[中国共产党](中国共产党.md)[中央权力机构](https://zh.wikipedia.org/wiki/中国共产党中央委员会)的[主要负责人](https://zh.wikipedia.org/wiki/中共中央主要负责人)，也是[中华人民共和国](中华人民共和国.md)实际上的[最高领导人](https://zh.wikipedia.org/wiki/中華人民共和國最高領導人)及[政治排名](https://zh.wikipedia.org/wiki/党和国家领导人#政治排名)最高的[正国级](https://zh.wikipedia.org/wiki/国家级正职)职务。
