# 概述

[**中华人民共和国主席**](https://zh.wikipedia.org/wiki/中华人民共和国主席)，简称**国家主席**，是[中华人民共和国](中华人民共和国.md)的[国家机构](https://zh.wikipedia.org/wiki/中华人民共和国国家机构)，为礼仪性和象征性的[国家代表](https://zh.wikipedia.org/wiki/虚位元首)，地位从属于[全国人民代表大会](https://zh.wikipedia.org/wiki/全国人民代表大会)，与[全国人大常委会](https://zh.wikipedia.org/wiki/全国人民代表大会常务委员会)共同行使职权，是目前[中华人民共和国政治](https://zh.wikipedia.org/wiki/中华人民共和国政治)[排名第二](https://zh.wikipedia.org/wiki/党和国家领导人#政治排名)的[正国级](https://zh.wikipedia.org/wiki/国家级正职)职务。

- 1954年9月27日，首次设置
- 1968年—1975年，缺位
- 1975年—1982年，废除
- 1983年6月18日，恢复设置
