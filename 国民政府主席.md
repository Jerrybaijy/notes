# 概述

[**国民政府主席**](https://zh.wikipedia.org/wiki/国民政府主席)（[1925年7月1日](<广州国民政府 (1925年).md> "汪精卫将中华民国陆海军大元帅大本营改组为国民政府")—[1948年5月20日](中华民国总统.md "中华民国实行宪政，国民政府主席改称中华民国总统")），少数文献记为**国民政府委员会主席**，全称**中华民国国民政府主席**，是[中华民国](中华民国.md)[国民政府](国民政府.md)时期的[国家元首](中华民国国家元首.md)。

国民政府主席由[国民政府委员会](https://zh.wikipedia.org/wiki/國民政府委員會)委员互选选出，国府委员多为[中国国民党](中国国民党.md)党内要员。1925年至1928年，国民政府主席的职权与其他委员相同，并无特殊的地方，这时期的国民政府为[集体领导](https://zh.wikipedia.org/wiki/集体领导)。随著1928年10月进入[训政时期](https://zh.wikipedia.org/wiki/訓政時期)，国民政府主席的权力增加，主席一职由[合议制](https://zh.wikipedia.org/wiki/合议制)变成首长制，也正式成为中华民国的[国家元首](https://zh.wikipedia.org/wiki/国家元首)。随著《中华民国国民政府组织法》的修改，国民政府主席的职权也有所不同，通常随著[蒋介石](蒋介石.md)的去留而变动：如1931年蒋中正下野时，修改《中华民国国民政府组织法》，使主席变成不负实际政治责任，因此[林森](https://zh.wikipedia.org/wiki/林森)在担任主席的12年间只是[虚位元首](https://zh.wikipedia.org/wiki/虛位元首)；直到1943年林森逝世后，蒋中正代理主席进而真除，主席一职又恢复成首长制。1937年至1945年[抗日日战争](中国抗日战争.md)期间，中国处于战时政治体制，国民政府实际最高领导人是[中国国民党总裁](https://zh.wikipedia.org/wiki/中國國民黨總裁)兼[国民政府军事委员会](https://zh.wikipedia.org/wiki/國民政府軍事委員會)委员长[蒋介石](蒋介石.md)。
