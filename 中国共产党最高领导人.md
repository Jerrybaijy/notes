# 概述

**中国共产党最高领导人**，是[中国共产党](中国共产党.md)实际上的最高领导人，区别于[中共中央主要负责人](中共中央主要负责人.md)。

中国共产党的实际最高领导人沿革，在不同历史时期呈现出不同的特点：[大革命](https://zh.wikipedia.org/wiki/国民革命军北伐)与[第一次国共内战](第一次国共内战.md)前期受共产国际影响变动频繁；[遵义会议](https://zh.wikipedia.org/wiki/遵义会议)后[毛泽东](毛泽东.md)逐步确立领导地位；改革开放初期出现了“实际最高领导人（政治权威）”与“[名义最高职务](中共中央主要负责人.md)”相分离的特殊时期；而自1989年后，则全面走向党、政、军最高职务“三位一体”的制度化继承。

1. **“权威”与“职务”的分合**：
   - **统一期**：[陈独秀](https://zh.wikipedia.org/wiki/陈独秀)时期、[毛泽东](毛泽东.md)后期（1945—1976）、[华国锋](https://zh.wikipedia.org/wiki/华国锋)时期（1976—1978）、[江泽民](https://zh.wikipedia.org/wiki/江泽民)/[胡锦涛](https://zh.wikipedia.org/wiki/胡锦涛)/[习近平](https://zh.wikipedia.org/wiki/习近平)时期（1992至今）。
   - **分离期**：遵义会议后至七大前（1935—1945，[毛泽东](毛泽东.md)为主导，[张闻天](https://zh.wikipedia.org/wiki/张闻天)负总责）；改革开放初期（1978—1989，[邓小平](https://zh.wikipedia.org/wiki/邓小平)为主导，[胡耀邦](https://zh.wikipedia.org/wiki/胡耀邦)/[赵紫阳](https://zh.wikipedia.org/wiki/赵紫阳)任名义最高职务）。

2. **关键权力的依托**：

   历史经验表明，中共实际最高领导权的归属，除了党内最高职务外，**对军队的领导权（中央军委主席职务）以及在关键历史时刻建立的政治威望**，往往是决定谁是“实际最高领导人”的决定性因素。

以下按照时间顺序，详细梳理中共实际最高领导人的更替逻辑，并对比各时期的[名义最高职务](中共中央主要负责人.md)的担任者：

# 历任最高领导人

## 建党初期与土地革命时期

这一时期的特点是共产国际指导力极强，最高领导人更替较为频繁，实际领导人基本与党内最高职务重合，但后期出现了决策权向军事/政治顾问倾斜的情况。

## 毛泽东领导地位的确立与巩固时期

这一时期实现了从军事指挥权到全面政治领导权的转移，并最终通过七大将毛泽东的领导地位在职务与思想上完全固定下来。

| ----------------- | ------------------------------------------------ | -------- | ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| 1935.02 – 1943.03 | [毛泽东](毛泽东.md)                              |          | [张闻天](https://zh.wikipedia.org/wiki/张闻天) | 遵义会议后“常委分工”，由张闻天接替博古在中央负总责（名义最高职务）。毛泽东在红军长征及到达延安后，通过军事胜利、延安整风运动，逐渐成为党和军队的实际最高决策者。 |

| 1945.06 – 1976.09 | [毛泽东](毛泽东.md)                              |          | 毛泽东                                         | 中共七大正式确立毛泽东思想为指导思想，撤销总书记职务，设“中央委员会主席”。毛泽东终身担任该职务，集党政军最高权力于一身。                                         |

## 过渡期与双重领导格局时期

毛泽东逝世后，中共经历了从华国锋的“职务集权”到邓小平以“政治权威和军委主席身份”主导决策的过渡。

| ----------------- | ---------------------------------------------- | -------- | --------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1976.10 – 1978.12 | [华国锋](https://zh.wikipedia.org/wiki/华国锋) |          | 华国锋                                                                            | 毛泽东逝世及粉碎“四人帮”后，华国锋接任党政军最高职务。这一阶段名义职务与实际权责一致。                                                                                                 |
| 1978.12 – 1981.06 | [邓小平](https://zh.wikipedia.org/wiki/邓小平) |          | 华国锋                                                                            | 十一届三中全会被视为转折点。邓小平重新确立了思想与政治路线，华国锋虽仍任中央主席，但实际决策中心已转移至邓小平及老一辈革命家。                                                         |

| 1987.01 – 1989.06 | [邓小平](https://zh.wikipedia.org/wiki/邓小平) |          | [赵紫阳](https://zh.wikipedia.org/wiki/赵紫阳) (邓小平继续任中央军委主席)         | 胡耀邦辞职后，赵紫阳接任代理总书记并在十三大上正式当选总书记。邓小平继续担任中央军委主席，仍然是党内的最终决策者。                                                                     |

## “三位一体”体制的形成与巩固时期

自1989年起，中共吸取了政治权威与最高职务分离的经验，逐步建立并固化了由党内最高领导人同时兼任**中共中央总书记**、**国家主席**、**中央军委主席**的“**三位一体**”领导体制。

| ----------------- | --------------------------------------------------------------------------------------------------------------------------- | -------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1989.06 – 1992.11 | [邓小平](https://zh.wikipedia.org/wiki/邓小平) (政治权威) 与 [江泽民](https://zh.wikipedia.org/wiki/江泽民) (核心) 共同过渡 |          | [江泽民](https://zh.wikipedia.org/wiki/江泽民) | 1989年十三届四中全会接任总书记，同年底接任中央军委主席。1989—1992年间（特别是1992年邓小平发表南方谈话期间），邓小平仍拥有极高的政治权威；1992年十四大后，邓小平完全退出领导层，江泽民全面独立行使最高领导权。 |

| 2012.11 – 至今    | [习近平](https://zh.wikipedia.org/wiki/习近平)                                                                              |          | 习近平                                         | 十八大当选总书记并同时接任中央军委主席，十九大、二十大连任。十八届六中全会明确了习近平作为党中央的核心、全党的核心地位。                                                                                      |
