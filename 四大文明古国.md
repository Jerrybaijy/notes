# 概述

[**四大文明古国**](https://zh.wikipedia.org/wiki/四大文明古国)，或称**四大古文明**，为人类文明最早诞生的地区，分别是：

- [**古巴比伦**](巴比伦.md)：位于[两河流域](两河流域.md)，今属[伊拉克](https://zh.wikipedia.org/wiki/伊拉克)。
- [**古埃及**](https://zh.wikipedia.org/wiki/古埃及)：位于[尼罗河](https://zh.wikipedia.org/wiki/尼罗河)流域和[恒河](https://zh.wikipedia.org/wiki/恒河)流域，今属[埃及](埃及.md)。
- [**古印度**](https://zh.wikipedia.org/wiki/印度河流域文明)：位于[印度河](https://zh.wikipedia.org/wiki/印度河)流域，今属[印度](https://zh.wikipedia.org/wiki/伊拉克)、[巴基斯坦](https://zh.wikipedia.org/wiki/巴基斯坦)等。
- [**中国**](中国.md)：位于[黄河](https://zh.wikipedia.org/wiki/黄河)流域，今属[中华人民共和国](中华人民共和国.md)。

这个概念由[梁启超](梁启超.md)在其写于1900年的《[二十世纪太平洋歌](https://zh.wikipedia.org/wiki/二十世纪太平洋歌)》文中首先提出，只在[汉字文化圈](https://zh.wikipedia.org/wiki/汉字文化圈)流行，世界其他地方均以“[文明摇篮](文明摇篮.md)”等字眼来称呼文明的发源地，通常也不将以上四个文明并称为最古老的古文明。
