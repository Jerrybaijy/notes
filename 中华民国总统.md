# 概述

[**中华民国总统**](https://zh.wikipedia.org/wiki/中华民国总统)，是[中华民国](中华民国.md)[中华民国政府](中华民国政府.md)时期的[国家元首](https://zh.wikipedia.org/wiki/国家元首)，设立于1948年，继承[国民政府主席](国民政府主席.md)的职能。
